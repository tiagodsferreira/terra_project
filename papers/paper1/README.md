# New Ecological Paradigm Scale Revised (NEPS- R) Evidence for a Two-Factor Structure and Measurement Invariance – Analysis Pipeline

This repository contains the complete R workflow for analyzing the New Ecological Paradigm (NEP) scale data collected from mothers and fathers of children in Portuguese families. The pipeline sequentially handles data preparation, missing data diagnostics, outlier treatment, descriptive statistics, confirmatory factor analysis (CFA), model comparison, and dyadic invariance testing.

## Project Structure:

```
├── data/
│   ├── data.sav              # Raw input data
│   ├── data_preped.sav       # Prepared data (output of script 1)
│   └── data_clean.sav        # Cleaned data (output of script 3)
├── code/
│   ├── 1_Data_Prep.r         # Import, exclusion criteria, age calculation, reverse-coding
│   ├── 2_Missing_Data_Analysis.R # MCAR/MAR tests, missing patterns, response rates
│   ├── 3_Outliers_Analysis.R # Univariate (Z-score) and multivariate (Mahalanobis) outlier detection
│   ├── 4_Sociodemographic_Descriptives.R # Frequencies and descriptives for demographics
│   ├── 5_NEPS_1D_Analysis.r  # Unidimensional CFA (15 items → 10-item final model)
│   ├── 6_NEPS_5D_Analysis.r  # Five-dimension CFA (Growth, Antiantro, Fragility, Rejection, Change)
│   ├── 7_NEPS_2D_Analysis.r  # Two-dimension CFA (Ecocentrism, Anthropocentrism)
│   ├── 8_NEPS_Descriptives.r # Item-level stats, composite scores, and combined correlation matrix
│   ├── 9_NEPS_Compare_Models.r # Fit indices and Omega comparison across 1D, 2D, and 5D models
│   └── 10_NEPS_Diadic_Model.r # Dyadic invariance (configural, metric, scalar, strict) and Wald tests
└── README.md
```

## Software Requirements

| Dependency | Purpose |
| ---------- | ------- |
| R (>= 4.0) | Core environment |
| haven      | Read/write SPSS (.sav) files |
| dplyr      | Data manipulation |
| tidyr      | Data reshaping |
| lubridate  | Date and age calculations |
| naniar     | Missing data visualization |
| mice       | Missing data patterns |
| moments    | Skewness and kurtosis |
| Hmisc      | Correlation matrices |
| lavaan     | Confirmatory Factor Analysis |
| semTools   | Fit measures for CFA |
| psych      | Omega reliability |

All required packages can be installed via install.packages().

## Usage

All scripts must be executed in numerical order (1 to 10), as each subsequent script reads the .sav file generated by the previous one.

Place the raw data file (data.sav) inside the data/ folder.

Run the scripts sequentially from the code/ directory:

```
Rscript code/1_Data_Prep.r
Rscript code/2_Missing_Data_Analysis.R
Rscript code/3_Outliers_Analysis.R
Rscript code/4_Sociodemographic_Descriptives.R
Rscript code/5_NEPS_1D_Analysis.r
Rscript code/6_NEPS_5D_Analysis.r
Rscript code/7_NEPS_2D_Analysis.r
Rscript code/8_NEPS_Descriptives.r
Rscript code/9_NEPS_Compare_Models.r
Rscript code/10_NEPS_Diadic_Model.r
```

Results are printed to the R console (no separate output files are generated beyond the intermediate .sav datasets).
